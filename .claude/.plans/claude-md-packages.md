# Дополнение CLAUDE.md пакетов api и web

## Контекст

Пользователь перенёс блоки про api и web из корневого `CLAUDE.md` в `apps/api/CLAUDE.md` и `apps/web/CLAUDE.md`. Теперь он просит дополнить эти два файла и спрашивает, нужно ли указывать пути к ним в корневом `CLAUDE.md`.

Проверка переноса:
- **Перенос точный.** Отсортированные строки трёх файлов совпадают со старым корневым файлом: 98 строк, `diff` пуст.
- **Разделение верное.**
  - В корне остались команды, `packages/shared`, версии, стиль, ветки, PR и коммиты.
  - В api ушли Nest, Prisma, авторизация, категории и транзакции.
  - В web ушли Next, FSD, shadcn, авторизация, формы и страницы.

**Ответ на вопрос: да, пути в корне указать нужно.** Claude Code подгружает вложенный `CLAUDE.md` лениво, только когда читает файл из этой папки.
- Без упоминания в корне Claude не знает о правилах пакета, пока не откроет его файл. Например, при планировании, запуске команд из корня или работе сразу с двумя пакетами.
- Пути нужно указать **обычным текстом, а не `@`-импортом.** Импорт `@apps/api/CLAUDE.md` грузил бы файл всегда, и разделение потеряло бы смысл.

Попутно найдено:
- **Текущая ветка не та.** Открыта `ci/github-claude-mention`, а PR #8 уже `MERGED`.
- **В корне лежит неотслеживаемый файл `185.121.225.35`.** Это бинарные данные `utmpx` от 19 октября. Не трогаю, решает пользователь.

## План

### Git
1. `git stash -u -- CLAUDE.md apps/api/CLAUDE.md apps/web/CLAUDE.md`, затем `git switch main && git pull`.
2. Отдельной командой проверить, что `gh pr view 8 --json state` показывает `MERGED`. Затем удалить `ci/github-claude-mention` локально и на GitHub.
3. `git switch -c docs/claude-md-packages`, `git stash pop`.

### Корневой `CLAUDE.md`
- После вступления добавить раздел «Пакеты»:
  - правила api лежат в `apps/api/CLAUDE.md`, правила web — в `apps/web/CLAUDE.md`;
  - Claude подгружает их сам при работе с файлами пакета;
  - если задача затрагивает пакет, а его файлы ещё не открывались, сначала прочитать его `CLAUDE.md`.
- В «Архитектуру» перед абзацем про shared добавить краткую карту:
  - `packages/shared` → api и web;
  - web обращается к api только по HTTP с сервера Next;
  - порты 3000 и 3001.
- Строку про web-Vitest (`vitest.config.mts`, алиас, окружение node, тесты `lib`-сегментов) перенести в web. В корне оставить общее: тесты рядом с кодом как `*.spec.ts` и пример запуска одного теста.
- Фразу «В api включён type-aware `recommendedTypeChecked`» перенести из «Стиля» в api.

### `apps/api/CLAUDE.md`
Текст пунктов не менять, только структура и дополнения:
- **Шапка:** `# apps/api — бэкенд (NestJS 12)`, строка «Общие правила: корневой `CLAUDE.md`».
- **`## Команды`** (новое, по `package.json`): `npm run <script> -w @expense-tracker/api`.
  - `dev`, `build`, `lint`, `typecheck` и `test` сначала вызывают `prisma generate`.
  - `test:watch`, `db:generate`, `db:migrate`, `db:deploy`, `db:studio`.
  - Обходной путь, если `migrate dev` падает в неинтерактивной оболочке на предупреждениях: `prisma migrate diff --from-config-datasource --to-schema … --script` в новую папку миграции, затем `migrate deploy`.
  - Новый модуль: репозиторий — единственный, кто обращается к своей модели Prisma; связь с другими модулями через `CommandBus`/`QueryBus`. Так устроены все модули.
- **`## Стек`:** Nest ESM, Prisma, линтер `recommendedTypeChecked` (перенос из корня).
- **`## Модули`:** авторизация, категории, транзакции. Пометки «(api)» убрать.
- **`## Тесты`** (новое, проверено по коду): Vitest, `*.spec.ts` рядом с кодом. `Test.createTestingModule` не используется: класс создаётся через `new`, зависимости — объекты с `vi.fn()` в функции `setup()`, приведённые через `as unknown as`. Образец: `users/commands/update-user-name.handler.spec.ts`.

### `apps/web/CLAUDE.md`
- **Первая строка `@AGENTS.md`.** Claude Code сам не читает `AGENTS.md` с правилом Next 16 «сначала `node_modules/next/dist/docs/`». Next (`generate-agent-files.js`) пишет только `AGENTS.md`, поэтому импорт безопасен.
- **Шапка:** `# apps/web — фронтенд (Next.js 16)`, строка «Общие правила: корневой `CLAUDE.md`».
- **`## Команды`** (новое):
  - `npm run <script> -w @expense-tracker/web`: `dev`, `build`, `lint` (`eslint .`), `typecheck` (сначала `next typegen`), `test`, `test:watch`;
  - `npx shadcn@latest add <name>` из `apps/web`.
  - Предупреждение: корневой `npm run build` при запущенном `npm run dev` удаляет `apps/api/dist` и роняет api. Пока работает dev, собирать только web.
- **`## Стек и тесты`:** Next, Tailwind, линтер плюс строка про Vitest из корня.
- **`## Архитектура (FSD)`**, **`## UI`**, **`## Авторизация`** — как есть.
- **`## Формы`:** сюда перенести абзац про русскую локаль Zod (`shared/config/zod.ts`), который сейчас по ошибке лежит в «Странице транзакций».
- **`## Страницы`:** главная и транзакции.
- Пометки «web» в заголовках пунктов убрать.

### Коммит и PR (после согласия пользователя)

- PR по правилам из раздела «Pull request», заголовок «Разделение CLAUDE.md по пакетам».

- `npm run format:check`.
