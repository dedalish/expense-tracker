## Что сделано

- Новая тема web: тёпло-серый фон, белые карточки без обводок, шалфейно-зелёный акцент, шрифт Onest.
- Боковое меню на широком экране — узкая колонка с иконками и подсказками, на телефоне выдвигается с подписями.
- Главная собрана плиткой: доходы, расходы, баланс месяца в цветной карточке, крупнейшие категории и шкала «Потрачено из доходов».
- Суммы в списках транзакций на цветных плашках: зелёная для дохода, красноватая для расхода.

## Зачем

Прежний интерфейс был стандартной темой shadcn без своего лица. Новая тема сделана по референсу дашборда, а шкала показывает главное для трекера расходов — какая часть доходов уже потрачена.

## Изменения в коде

- Frontend (`apps/web`): токены темы в `globals.css` (свои цвета `income`, `expense`, `hero`), классы `button`, `card`, `input`, `select`, `textarea` под тему; новые `shared/ui/logo-mark.tsx` и `widgets/month-summary/ui/spend-gauge.tsx`; `LogoutButton` получил проп `view`.
- Документация: `apps/web/CLAUDE.md` — описание темы и ручных правок shadcn-компонентов.

## Как проверить

Запуск: `npm run dev` → web http://localhost:3000.

Тесты:

```bash
npm run test -w @expense-tracker/web
```

Шаги ручной проверки:

1. Войти и открыть главную: три карточки итогов, баланс в зелёной карточке, шкала показывает долю расходов от доходов.
2. Выбрать месяц без доходов: вместо шкалы пояснение «Доходов в этом месяце нет».
3. Сузить окно до 390px: меню прячется за кнопку в шапке и выдвигается с подписями.
